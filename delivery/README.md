# つるりんちょ。お試しセット 記事LP

完成したLPのHTML・画像とZIPです。

## ダウンロードと表示

1. [公開用ZIP](kaminidoramawo-trial-article-lp-20261005.zip) を開き、Download raw file（下向き矢印）でダウンロードしてください。
2. ZIPを展開してください。
3. 展開したフォルダの `index.html` をChromeなどのブラウザで開いてください。

HTMLと `assets` は同じフォルダ構成のまま使用してください。GitHubのHTML画面はソース表示のため、LPの閲覧にはダウンロード後のブラウザ表示を使います。

## 内容

成分・使い方・髪質別ラインを紹介し、税込2,200円のお試しセットへの購入導線につなげた記事LPです。クロージングには3つの組み合わせを使い比べる案内を追加。PR表記と注釈を実装しています。

スマホ390px・PC1280pxで画像読み込み、購入リンク、ボタン動作を確認。外部Webサイトへの公開は未実施です。
